# 📝 Task Management System

![PHP](https://img.shields.io/badge/PHP-7.4+-777BB4?style=for-the-badge&logo=php&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL-5.7+-4479A1?style=for-the-badge&logo=mysql&logoColor=white)

A simple, robust, and responsive **Task Management System** built with **PHP, MySQL, and XAMPP**. It allows organizations to streamline workflow by enabling admins to manage employees, assign tasks, track progress, and send notifications.

---

## 🚀 Features

### Admin
- **User Management**: Add, update, view, and delete employee profiles.
- **Task Management**: Create, assign, update, and delete tasks.
- **Progress Tracking**: Monitor task statuses (Pending, In Progress, Completed).
- **Deadline Monitoring**: Keep track of due dates and overdue tasks.
- **Notifications**: Push notifications for important updates and task assignments.

### Employee
- **My Tasks**: View assigned tasks and deadlines.
- **Status Updates**: Update the progress of assigned tasks.
- **Profile Management**: Update personal profile details.
- **Notifications**: Receive alerts when new tasks are assigned.

---

## 💻 Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP (7.4 or higher)
- **Database**: MySQL (5.7 or higher)
- **Environment**: XAMPP / WAMP / MAMP

## 🛠️ Installation & Setup

Follow these steps to run the project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/darshgami/task-management-system.git
   ```

2. **Move to Server Directory**
   Move the project folder to your local server directory:
   - For XAMPP: `C:\xampp\htdocs\`
   - For WAMP: `C:\wamp\www\`

3. **Database Setup**
   - Open XAMPP Control Panel and start **Apache** and **MySQL**.
   - Open your browser and go to `http://localhost/phpmyadmin/`.
   - Create a new database named `task_management_db`.
   - Click on the **Import** tab and upload the `task_management_db.sql` file provided in the root of the project.

4. **Run the Project**
   - Open your browser and go to `http://localhost/task-management-system/`.
